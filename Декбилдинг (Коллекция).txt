Привет! Мы переходим к проектированию экрана "Коллекция и Декбилдинг" (сборка колод) для нашей ККИ на Unity 6 и Go. Нам нужна безопасная клиент-серверная логика, учитывающая наши классовые правила.

Пожалуйста, строго соблюдай правила:
1. Я абсолютно не знаю программирования. Пиши код (C# для Unity и Go для сервера) с подробнейшими комментариями на русском языке, объясняя каждую строчку "на пальцах".
2. Вся финальная проверка честности сборки колоды происходит строго на сервере Go для защиты от читеров.

Вот логика работы Декбилдера:
- При создании новой колоды в Unity игрок выбирает ID Персонажа (Героя).
- На основе выбранного героя включается фильтр карт: игроку разрешено добавлять в колоду только Общие карты (ID Класса = 0) и Карты этого Героя (например, ID Класса = 1 для Никотина). Также заложи архитектуру под будущие Гибридные карты (которые могут принадлежать двум классам одновременно).
- В колоде должно быть ровно 30 карт. Обычных карт в колоду можно положить максимум 2 копии, а Легендарных (уникальных) — максимум 1 копию.
- При нажатии "Сохранить", Unity отправляет на сервер Go пакет данных: ID Игрока, Название колоды, ID Выбранного Героя и список (массив) из 30 ID карт.

Логика Валидации на сервере Go:
- Сервер принимает пакет данных колоды от игрока.
- Сервер поочередно проверяет:
  1. Количество карт в массиве строго равно 30.
  2. Никакая обычная карта не повторяется больше 2 раз, а легендарная — больше 1 раза.
  3. Все карты в списке соответствуют правилу класса (либо общие, либо принадлежат классу выбранного героя, либо являются разрешенными гибридными).
- Если проверка пройдена, сервер сохраняет колоду в базу данных игрока и возвращает статус "Успешно". Если проверка провалена, сервер отклоняет сохранение и отправляет код ошибки.

Пожалуйста, покажи:
1. Структуру данных JSON для сохранения колоды.
2. Код на Go (с комментариями "на пальцах"), реализующий все три этапа проверки колоды на сервере.
3. Код на C# для Unity, который собирает данные из UI (интерфейса) и отправляет их в формате JSON на сервер.
